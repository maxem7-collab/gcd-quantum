# GCD Quantum

Analizador de oscilografías de relevadores de protección con confiabilidad operativa: diagnóstico con certeza calibrada, protocolo PARE, análisis causa-raíz en formato DOE, anatomía del evento y experiencia operacional por equipo.

Esta es la versión web instalable (PWA). Funciona sin conexión una vez abierta.

- **iPhone o iPad:** abre la página en Safari y toca Compartir → Agregar a pantalla de inicio.
- **Android:** Chrome → Instalar app.
- **Windows:** Edge o Chrome → Instalar GCD Quantum.

Los registros (COMTRADE, CFF, SEL CEV y EVZIP) se procesan en el propio dispositivo y no se envían a ningún servidor. El historial de experiencia operacional se guarda en el dispositivo y se puede exportar o importar en JSON.
